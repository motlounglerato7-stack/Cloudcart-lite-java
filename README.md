# CloudCart Lite - Java Console Application

## Overview
CloudCart Lite is a beginner-friendly Java console application that simulates a simple online shopping cart system.

The project demonstrates object-oriented programming, basic data structures, clean logic separation, and customer-focused software design.

## Problem Statement
Many online shopping platforms require reliable cart systems that allow customers to view products, add items to a cart, apply discounts, and checkout. This project provides a simplified version of that process using Java.

## Features
- View available products
- Add products to cart
- Validate product quantity and stock
- View cart items
- Calculate total price
- Apply discount codes
- Generate checkout summary

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Scanner
- Git and GitHub

## Classes Used
- `Product` - stores product details
- `CartItem` - stores selected product and quantity
- `ShoppingCart` - handles cart operations and discounts
- `Main` - runs the menu-driven application

## Discount Codes
- `AMAZON10` - 10% discount
- `STUDENT15` - 15% discount
